# Симулятор: отпизди Галюху — v2.0

Космический шутер на чистом HTML5 Canvas + JS (без сборки, без зависимостей). Работает прямо из папки,
на GitHub Pages — достаточно загрузить файлы в репозиторий.

## Как запустить

```bash
# локально
python3 -m http.server 8000     # открыть http://localhost:8000
# или просто двойным кликом по index.html
```

Файлы в репозитории должны лежать в одной папке (как сейчас): `index.html`, `style.css`, `game.js`,
и ассеты `shit1..4.png`, `shit_final.png`, `snd_*.mp3`, `crystals.mp3`. Имена регистрозависимы — на
GitHub Pages `Shit1.png` ≠ `shit1.png`. Если спрайт или звук не нашёлся, игра не падает: спрайт
рисуется процедурно, а звуки синтезируются WebAudio.

## Что починено в v2.0 (главное — игра перестала быть непроходимой)

Оригинальная версия ломалась арифметикой, а не сложностью. Три причины:

| # | Было (v1.0) | Стало (v2.0) |
|---|---|---|
| 1 | `toSpawn = 4 + wave*2` и `interval = max(350, 1200 - wave*40)` — с 14-й волны спавн обгонял убийства **даже при 100% точности** | Кривая с плато + **гейм-мастер**: темп волны считается от фактического DPS игрока, интервал спавна никогда не меньше `1.40 ×` времени убийства одного врага |
| 2 | 3 жизни, каждая долетевшая Галюха = мгновенный `gameOver` на поздних волнах | Двойки (1..5) = здоровье, жизнь снимается только когда дневник пуст; на wave 20 смерть шла ~30/9.5/2.9 с в v1.0 — теперь волна конечна |
| 3 | Прогресса не было: `fireRate` 140 мс и 15 урона навсегда | После каждой волны — 1 из 3 случайных апгрейдов (12 штук), редкие элита-Галюхи с дропом ×2 |
| 4 | Босс на волнах кратно 5 был **легче** соседних (440 HP, не двигался) | Босс 900+wave·60 HP, ИИ с телеграфами (пила-полоса с окном 900 мс, 5–6 пулемётов, 2 прыжка с i-frames), викторина «задача на доске» как награда за агрессию |
| 5 | `shadowBlur` на каждом объекте → 5 fps на 500 частицах | Glow предрендерится в кэш (8 спрайтов), 12 `drawImage` вместо `shadowBlur` |
| 6 | Скорость врагов = px/кадр → на 144 Гц игра была в 2.4 раза быстрее | Всё в px/сек, `dt` нормализован (0.8..1.4) |
| 7 | `Math.random()` в отрисовке (выхлоп) — в паузе сдвигался будущий спавн | Рендер не трогает логику и ГШЧ; вся анимация на игровом времени `gameTime` |

Баланс проверяется не «на глаз», а числами:

```bash
node balance_v2.js        # статическая проверка кривой (запас по DPS, окно на прицел)
cd ../test && node run_tests.js   # 6 ботов × 10 сидов + UI-смоук: 30 проверок, 60 прогонов (~95 с)
node run_tests.js --fast          # то же на 3 сидах (~35 с)
node run_tests.js --det           # только побитовая воспроизводимость
node ui_smoke.js                  # один смоук UI/DOM (jsdom): меню, HUD, пикер, пауза, game over
```

Последний прогон: супер-игрок 28–33 волны, обычный человек 25–34 (9 из 10 живых), «стою на месте» и
«не стреляю» = смерть на 14-й, босс убит на всех сидах, ноль исключений, результат **побитово
воспроизводим** (тот же сид → та же игра).

### Честность (без «вас наказали за то, что не успели увидеть»)

- враг не спавнится ближе 130 px к игроку и не таранит, пока не залетел в строку;
- пропущенный враг, пока есть двойки, = одна двойка (и +1 волне к «потерянным двойкам» в стате);
- если дневник пуст и вас сбило — жизнь уходит сразу, не дожидаясь утечки;
- за таймаут викторины штрафа нет (нет ответа = 1 штрафной враг −60 очков);
- после i-frames 350 мс неуязвимости; касание босса во время викторины не бьёт;
- очередь спавна укорачивается (с 12-й волны), если на экране больше `onCap ≈ 2.5 + DPS/1.35` врагов —
  волна кончается, не превращаясь в стену.

## Управление

`WASD`/`стрелки` + мышь (или `IJKL`-стрейф для тачпада, `Space`/ЛКМ — огонь, `Shift`/`E`/правая кнопка — рывок).
Приседание нет; на тач-устройствах — виртуальный джойстик. `P` — пауза.

## Тестовый интерфейс `window.__DBG`

`__DBG.state()` — волна/счёт/двойки/жизни/`toSpawn`/`pressure`/`pain`/`gameTime`/`stat`/`difficulty(wave)`;
`__DBG.set({...})` — задать `wave`/`lives`/`grades`/`firing`/`pointerX`; `__DBG.restart(fromWave)`;
`__DBG.forceWave(n)`; `__DBG.killAllEnemies()`; `__DBG.rollChoices(n)`; `__DBG.pickUpgrade(id)`;
`__DBG.setGrades(n)`; `__DBG.hit()` и `__DBG.clearIfr()` (принудительный урон без i-frames);
`__DBG.useCheat()`; `__DBG.playerDps()`; `__DBG.waveState()`. Счётчики (`leaks`, `gradeLost`, `livesLost`,
`quizBad`, `bossKilled`, …) лежат в `state().stat`.

## Идеи, если захочется продолжить

1. **Пачки апгрейдов** — сейчас 12 штук, хватает на ~25 волн; 20–24 штуки и 2–3 «синергии» (двойной выстрел + пробитие) дали бы причину играть забег заново.
2. **Режим «2 полугодия»** — вторая колода Галюх (физики/информатички) с другими паттернами, вместо одной.
3. **Таблица рекордов** в `localStorage` + «кирка дня» (общий сид, чтобы сравнивать с одноклассниками честно).
4. **Босс-викторина с реальными задачами** — массив задач вынести в `questions.js`, чтобы можно было
   дополнять без правки движка (сейчас 12 канонов, `answer % 10` даёт подсказку-остаток).
5. **Достижения** («не пропустить ни одной Галюхи на волне 20», «убить завуча без шпаргалок») — дёшево и очень по-школьному.

## Про «детерминированность»

Тесты полагаются на то, что `Math.random` в движке — единственный источник случайности, а таймеры
(музыкальный шедюлер) не влияют на геймплей. Поэтому любой `Math.random()`/`performance.now()` внутри
`draw*` — это баг, а не косметика: рендер вызывается и в паузе, и будущие спавны сдвигаются.
