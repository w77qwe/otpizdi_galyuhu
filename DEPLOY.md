# Как выкатить v2.0 на GitHub Pages (5 минут)

Игра по-прежнему «три файла в одной папке» — никакой сборки и зависимостей.

## 1. Что положить в репозиторий

В корень репозитория (там, где уже лежат `index.html` и ассеты):

```
index.html      ← заменить
style.css       ← заменить
game.js         ← заменить
README.md       ← опционально (на Pages он не нужен, но учителю показать полезно)
.nojekyll       ← создать пустой файл (иначе Jekyll проигнорирует служебные файлы/подчеркнутые имена)
shit1.png … shit4.png, shit_final.png, snd_*.mp3, crystals.mp3   ← ОСТАВИТЬ КАК ЕСТЬ, они в корне
tests/          ← папка с тестами, в git можно не класть (или положить — на Pages она не мешает)
```

## 2. Быстрая проверка перед коммитом (локально, в папке с игрой)

```bash
# все ли имена ассетов совпадают с учётом регистра (на Pages регистр ВАЖЕН)
grep -o "[A-Za-z0-9_./-]*\.\(png\|mp3\)" index.html game.js style.css | sed 's/.*://' \
  | sort -u | while read f; do [ -f "$f" ] && echo "OK   $f" || echo "НЕТ ФАЙЛА $f"; done
```

`НЕТ ФАЙЛА` — не страшно для запуска (спрайт рисуется процедурно, звуки синтезируются), но картинка
Галюхи тогда не покажется. Часто это просто разный регистр: `Shit1.png` vs `shit1.png`.

```bash
# саму игру — если стоит node + jsdom (нужен только для тестов)
cd tests && npm i && node run_tests.js --fast     # ~35 с, должно быть «ЗЕЛЁНОЕ НА 3 СИДАХ»
```

## 3. Залить

```bash
git add -A
git commit -m "v2.0: починен баланс (стена на 14-й волне), прокачка, босс, звук, retina + тесты"
git push origin main          # или master — как у вас настроено
```

Если Pages не отвечает сразу: **Settings → Pages → Branch: main /(root)** → Save.
Затем подождать 1–2 минуты и открыть `https://<логин>.github.io/<репо>/`.

## 4. Что проверить в браузере первым делом

1. Меню → «ИГРАТЬ» — на 1-й волне летится легко, двойки `6/6` в HUD.
2. Убить 5-ю волну → босс: есть телеграф пилы (мигающая зона ~0.9 с) и **окно**, чтобы уйти.
3. Конец волны → экран «ПРОКАЧКА» с 3–4 карточками, клик работает, HUD показывает «Прокачал: …».
4. `P` — пауза: картинка замирает (это специально, рендер остановлен).
5. Смерть → экран game over с подзаголовком, волной, счётом и списком прокачки.
6. Если mp3/png не подхватились — звук всё равно есть (синтез), враги — процедурные.

## 5. Если захочется «как было, но чуть-чуть»

Все числа баланса собраны в двух местах `game.js`, менять можно не глядя в код механик:

| что | где |
|---|---|
| базовые константы (`fireRate`, `bulletDamage`, `gradesMax`, `cheatCharges`, `maxEnemies`, `quizTime`) | `CFG` в начале файла |
| кривая сложности (HP/скорость/число врагов/интервал по волнам) | `function difficulty(wave)` |
| сколько «запаса» игроку обязательно оставлять | `DPS_MARGIN` (1.40) внутри `safeSpawnInterval()` |
| давление гейм-мастера (коридор) | `0.72 … 1.35` в блоке game-master |

После любой правки — `node balance_v2.js` (он читает `difficulty()` прямо из `game.js`) и `node run_tests.js --fast`.
Если «человек» стал умирать раньше 20-й волны или, наоборот, жить вечно — это тест покажет, а не ощущения.
